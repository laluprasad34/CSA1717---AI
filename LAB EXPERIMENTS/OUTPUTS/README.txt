SIMPLE AI PYTHON LAB PROGRAMS (1-10)

How to use:
1. Download and extract this ZIP file.
2. Open VS Code.
3. Click File > Open Folder and choose Simple_AI_Python_Programs.
4. Open a .py file.
5. Click the Run button, or open Terminal and type: python filename.py

Examples:
python 07_bfs.py
python 01_8_puzzle.py

These are simplified lab examples. The 8-puzzle uses BFS and may take longer for harder start states.
No extra packages are needed.
